# 実装計画と現状

simple caption tool v0.1.0。Windows向けのローカル画像キャプションツールです。

## フェーズ1 — 実装済み

- PySide6日本語GUI、サムネイル、プレビュー、複数選択、処理状態フィルター。
- キャラクター／画風プリセット、自然文／タグ／混合、トリガー、固定外見の記述切替。ファイル名の先頭N文字／N単語による画像別トリガーと抽出結果プレビュー。
- 画像解析と出力レンダリングを分離。構造化JSONからVLM不要で再生成。
- キャプション編集、選択／全件の文字列置換、手動編集の上書き保護。
- 既存UTF-8 TXT取込、画像と同名のUTF-8 TXT出力、既存ファイルのスキップ／バックアップ、同名衝突検出。
- 原画像の変更検知、画像単位の状態・解析履歴・モデル生出力の保存、失敗後の続行、途中再開。
- アプリ全体の最後の設定保存、JoyCaptionを初期値とするモデル復元、新規フォルダーへの設定引継ぎ、全画像の再解析ボタン。
- Qwen／JoyCaptionのモデル選択、固定版GGUF・mmproj・Windows CUDA推論エンジンの初回取得、SHA-256確認、ダウンロード途中再開。
- 認証付きループバック接続、画像のメモリ内前処理、非表示の子プロセス起動とバッチ終了時停止。
- 保存／再開／出力／ダウンロード／GUI操作／処理継続の自動テストと、実機評価スクリプト。

## 内部構成

| ファイル | 役割 |
|---|---|
| `captioner/core.py` | プロジェクトJSON、編集履歴、原画像の変更検知、出力形式、TXT保存 |
| `captioner/runtime.py` | 取得、検証、エンジンの起動終了、画像前処理、ローカル推論 |
| `captioner/catalog.json` | 固定された配布ファイル、サイズ、ハッシュ |
| `captioner/worker.py` | GUIを止めない解析スレッド、画像単位の結果通知 |
| `captioner/gui.py` | 画面、編集、出力、プロジェクト状態の保存 |
| `tools/evaluate.py` | ローカルモデルの再現可能な実機スモーク試験 |
| `tests/` | データ保護と主要ワークフローの検証 |

解析JSONは全文記述・固定外見を省いた記述・画風を省いた記述・内容タグ・外見タグ・画風タグを保持します。元モデルの観測にない情報をテンプレートだけで生成することはしません。出力は英語、任意の手動編集はUTF-8です。

## フェーズ2 — 次の品質評価

本人が用意した成人の画像と使用権のあるデータで、キャラクター／画風、写真／イラスト、一般／成人向けを層別に評価します。比較項目は対象物・衣服・動作・画風の正確さ、幻覚、婉曲表現・拒否、不要な固定外見や画風の混入、タグ品質、JSON成功率、秒／枚、VRAMです。

同一の画像・縮小サイズ・プロンプト・量子化条件を保存し、自然文とタグを人手採点します。拒否抑制版の名前や一般ベンチマークだけで成人向けキャプション品質を断定しません。必要に応じてJoyCaption専用の自然文プロンプトと構造化変換を分け、モデル本来の得意な指示形式でも比較します。

## フェーズ3 — 配布・大量データ向け

Python不要のWindows EXE、依存ライセンス文書の同梱、数万枚向け非同期スキャンとサムネイルキャッシュ、履歴の圧縮・復元UI、モデル別推論設定、GPU空きメモリを使った自動調整を追加する想定です。現版には正規表現置換・履歴復元ボタン・自動VRAM最適化はありません。

## 現版の制限

フォルダー走査・画像ハッシュ算出・JSON全体保存は同期処理です。非常に大きなデータセットでは待ち時間が発生します。大量の履歴はJSONが大きくなります。手動入力は400msの間に強制終了すると直前の入力が失われる可能性があります。アプリの強制終了時は内部推論プロセスが残る可能性があります。通常終了は解析終了を待って停止します。

モデル／依存関係の初回取得にはネット接続が必要です。固定したリリースが配布停止された場合はカタログの更新が必要です。モデル名の「uncensored」「abliterated」は正確さや無拒否を保証するものではありません。成人向け実画像の品質評価を終えるまではモデル採用は暫定です。
